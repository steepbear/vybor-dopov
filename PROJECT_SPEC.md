# Выбор допов — изменения V7

**Роли:** `system_admin` создаёт филиалы и методологов; `methodologist` связан с одним филиалом и управляет учётными записями учеников своего филиала; `student` видит только себя.

**Пароли и логины:** сотрудники: email + пароль; ученики: логин вида `IvanovI-001` + короткий пароль вида `lipa4827`. Создание, сброс, блокировки через Edge Function и проверенные полномочия. Технический случайный email существует только как внутренний идентификатор Supabase Auth.

**Изменения БД:** новая таблица `public.student_accounts`; `profiles.is_active`; `private.v7_login_attempts`; RPC `public.v7_consume_login_attempt` исключительно для сервисной роли; политики чтения для нового справочника и администратора; закрытая служебная функция доступа без прямой записи Auth из браузера. Старый `students.full_name` не удаляется из-за совместимости с V6, новые значения равны логину.

**Порядок:** V5 SQL → V6 миграция (уже существует) → V7 SQL → bootstrap system_admin → Edge Function → публикация интерфейса → приёмочные тесты.

**V8 в будущем:** редактирование направлений, групп и расписаний с анализом влияния на подтверждённые выборы и архивированием.
