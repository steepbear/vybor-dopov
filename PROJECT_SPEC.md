# Выбор допов — модель V5

- Филиал — отдельная школа; методолог связан с **одним** филиалом, управляет параллелями 1–4 своего филиала.
- Один предмет из общего справочника может быть использован многими филиалами и параллелями; конкретные группы и их занятия привязаны к одной паре `branch_id` + `grade`.
- Ученик выбирает группы вручную, без лимита по количеству допов, при отсутствии временных пересечений; обычно не более одной группы на одно обычное направление.
- Олимпиада — полноценная группа с расписанием; методолог назначает предложения конкретным ученикам. Одному ученику можно назначить **много** олимпиад и он принимает каждую независимо.
- Принятые олимпиады и обычные группы конфликтуют на равных. Подтверждённый выбор заблокирован, пока методолог не откроет его.
- MVP GitHub Pages использует синтетические данные и `localStorage`, не предназначен для реальных данных детей.
- `schema.sql` — только первая схема PostgreSQL с закрытыми правами. Фактическая работа через Supabase требует Auth, RLS по филиалу/своему ученику, серверных атомарных проверок пересечений и подтверждений.
- UI V5: недельное расписание сверху; ниже карточки олимпиады и многострочный каталог групп.
