Проверка доступа методолога к филиалам

Отдельная страница для проверки авторизации и RLS. Она только читает базу, ничего не изменяет и не заменяет основное приложение V5.

1. Параметры проекта

Supabase → Connect (URL и publishable key), либо Settings → API Keys. Никогда не вставляй сюда Secret key, service_role или пароль самой базы.

2. Вход методолога

Пароль вводится прямо в браузере и отправляется только Supabase Auth по HTTPS; эта страница не сохраняет его или токен входа в localStorage.

3. Данные, доступные этому пользователю

4. Проверка изоляции филиалов

Проверяются точные идентификаторы тестовых записей. Другие существующие данные в филиале на результат не влияют.
