# Выбор допов — V5

Демонстрационный сайт для GitHub Pages. Данные по-прежнему сохраняются только в `localStorage` браузера. Никакой серверной базы к сайту **пока не подключено**.

## Что изменилось

- На экране ученика сверху размещено широкое недельное расписание с выбранными занятиями. Далее идут предложения олимпиад, затем каталог допов карточками в несколько столбцов (3 на широком экране, 2 на среднем, 1 на телефоне).
- Методолог может предложить одному ученику **несколько разных олимпиад**; ученик принимает каждую независимо. Конфликтующие по времени олимпиады блокируются.
- Переписаны отчёты, подтверждение, отзыв предложений, сохранение. Данные из локальных V3/V4 читаются при первом открытии V5 в том же браузере и по тому же URL.
- Создан `schema.sql` для подготовки PostgreSQL в Supabase. Он **не подключает** базу к сайту и **не выдаёт** публичных прав. Это первый шаг к настоящей системе с авторизацией и RLS.

## Как обновить GitHub Pages

В репозитории замените `index.html`, `style.css`, `data.js`, `app.js`. Сохраните `schema.sql` и документацию отдельно или в репозитории: файл SQL не должен содержать ключей или паролей (в данном файле их нет).

## Как создать безопасную пустую базу в Supabase

1. Создайте проект на https://supabase.com/dashboard (New project).
2. Откройте **SQL Editor → New query**.
3. Скопируйте текст `schema.sql` и нажмите **Run**.
4. В **Table Editor** должны появиться таблицы `branches`, `students`, `subjects`, `study_groups`, `group_sessions`, `time_slots`, `olympiad_offers`, `regular_selections`, `profiles`.
5. Данные учеников **не переносите**, пока не будут готовы авторизация, RLS-политики для филиала/ученика и серверная проверка конфликтов. Текущий `data.js` используется только для демо.
6. Позже подключается Supabase Auth, права методологов по одному филиалу, права учеников к собственным записям и операции записи через проверяемый серверный API/RPC.

Никогда не публикуйте пароль базы, секретные ключи или `service_role` в GitHub или фронтенд-файлах. `schema.sql` намеренно запрещает доступ `anon` и `authenticated` до добавления проверенных политик. В интерфейсе Supabase как владелец базы вы увидите таблицы через SQL Editor.

## Запуск локально

Можно открыть `index.html`, но надёжнее поднять локальный HTTP-сервер: `python -m http.server 8000`, затем зайти на `http://localhost:8000/`.
